SF GROUP PROFESSIONAL WEBSITE
================================

1. Open index.html in a browser.
2. The slider images are in:
   assets/images/slider/
3. To replace a slider image, keep the same filename:
   slide-1.svg
   slide-2.svg
   slide-3.svg
4. Replace YOUR_TEAM_FORM_LINK in index.html with the real team application form.
5. Replace YOUR_CLIENT_FORM_LINK in index.html with the real client project form.
6. Contact details currently use:
   +91 96212 96862
   samirfaisal411@gmail.com

This package is front-end only. Forms are external links so you can use Google Forms, Tally, Jotform, etc. without adding a server.
No emoji icons are used in the interface. Icons are drawn with CSS.
